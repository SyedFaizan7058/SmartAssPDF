ABOUT SMARTASSPDF

Document Tools with Less Friction.

SmartAssPDF brings everyday PDF and document workflows into one responsive, private workspace. Built for professionals and everyday users who want fast results without subscription walls.

Core Architecture Principles

Every component of SmartAssPDF is engineered around transparency, speed, and privacy:

100% Open-Source Engine Powered by Apache PDFBox, Apache POI, and Spring Boot without expensive third-party conversion APIs.
Temporary Job Storage Jobs are created in memory and files reside in temporary server folders with scheduled 30-minute auto-deletion.
No Account Wall All 16 tools are available on-demand with no required account, registration, or credit card.

Technology Stack

SmartAssPDF combines a lightweight, modern static frontend with a robust Java Spring Boot backend:

  • Frontend: High-performance static HTML5, CSS3 design tokens, vanilla ES6 JavaScript modules.
  • Backend: Java 17+, Spring Boot 3 REST API.
  • PDF Processing: Apache PDFBox for PDF manipulation, rendering, encryption, and merging.
  • Office Documents: Apache POI for DOCX, XLSX, and PPTX conversions.
  • HTML Rendering: OpenHTMLtoPDF for accurate markup-to-PDF rendering.
