ABOUT THIS TOOL

Why Sanitize PDF Documents?

Standard PDF files invisibly store author names, company IDs, software versions, GPS locations, and hidden XML packets. Sanitizing ensures zero personal data leaks.

Quick Definition & Overview
PDF Sanitization scrubs document information dictionaries, XMP metadata streams, embedded thumbnails, JavaScript actions, and private annotations.
  • Wipes author, title, producer, and modification timestamps
  • Removes embedded JavaScript and executable macros
  • Strips hidden XML packets and cached thumbnail previews

Frequently Asked Questions

What information is removed during PDF sanitization?

Sanitization strips author names, creating software, creation and modification timestamps, XMP XML metadata packets, embedded thumbnail images, and unique document tracking UUIDs.

Will sanitization affect document visual formatting?

No. The visible document pages, text, vector graphics, and images remain 100% untouched. Only invisible metadata packets are removed.
