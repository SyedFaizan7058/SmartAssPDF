Frequently Asked Questions

Find direct answers to common questions about file formats, conversion accuracy, privacy, limits, and technical specifications.

General & Access

What is SmartAssPDF?
SmartAssPDF is a lightweight, privacy-focused online document processing platform offering 16 essential PDF conversion, manipulation, and security utilities.
Is there any cost or subscription?
No. All 16 tools are 100% free and do not require paid subscriptions or credit cards.
Do I need to create an account?
No account or login is required. You can convert and manage documents immediately.

Formats & Validation

What formats are supported?
SmartAssPDF supports PDF, Microsoft Word (.docx), Excel (.xlsx), PowerPoint (.pptx), Images (.jpg, .jpeg, .png), and Web (.html).
What is the maximum file size?
The maximum individual file size is 50 MB. Multi-file tools support up to 20 files per request.
What happens if I pick an invalid file type?
SmartAssPDF validates file extensions and MIME types immediately in the browser, showing a clear error message without uploading invalid files to the server.

Privacy & Security

Are my documents stored permanently?
No. Documents are processed in isolated temporary folders and deleted automatically after 30 minutes by our scheduled cleanup service.
Are passwords stored in a database?
No database exists in the architecture. Passwords are used only in transient memory during encryption/decryption requests.
